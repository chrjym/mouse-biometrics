# Simulation Segment: Mouse Dynamics Continuous Authentication

This folder represents the **Simulation Segment** of the thesis **"Measuring Behavioral Fingerprints of Users in Mouse Trajectories for Continuous Authentication"**.

Currently in the **planning and design phase**, this segment formalizes the architecture, requirements, datasets, and evaluation methodology before running experimental simulations.
